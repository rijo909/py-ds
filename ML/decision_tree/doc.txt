# Decision Tree Algorithm Explained

## Key Components of Decision Trees

### Basic Structure
- **Decision Tree**: A flowchart-like structure where each internal node represents a "test" on an attribute, each branch represents the outcome of the test, and each leaf node represents a class label or continuous value.
- **Root Node**: The topmost node in the tree which represents the entire population or sample.
- **Internal Node**: A node that splits into further nodes based on a decision rule.
- **Leaf Node**: Terminal nodes that represent class labels or predicted values.
- **Branch**: A subsection of the entire tree that connects nodes.

### Splitting Criteria
- **Best Split**: The split that most effectively separates the data into distinct classes or reduces uncertainty the most.
- **Criterion**: Metrics used to evaluate the quality of a split:
  - **Gini Index**: Measures impurity (0 means all elements belong to a single class)
  - **Entropy**: Measures disorder or uncertainty (0 means perfect order)
- **Information Gain**: The reduction in entropy or Gini impurity from a split. Higher information gain means better splits.

### Algorithm Characteristics
- **Greedy Algorithm**: Decision trees make the locally optimal choice at each node (best split at that point) without considering global optimization.

### Potential Issues
- **Overfitting**: When the tree becomes too complex and captures noise in the training data, performing poorly on new data.
- **Tree Pruning Techniques** to prevent overfitting:
  - Limiting tree depth (max_depth)
  - Setting minimum samples required to split a node (min_samples_split)
  - Setting minimum samples required at a leaf node (min_samples_leaf)

## Simple Example: Should We Play Tennis?

Let's consider a simple dataset about whether to play tennis based on weather conditions:

| Outlook  | Temperature | Humidity | Windy | Play Tennis |
|----------|-------------|----------|-------|-------------|
| Sunny    | Hot         | High     | No    | No          |
| Sunny    | Hot         | High     | Yes   | No          |
| Overcast | Hot         | High     | No    | Yes         |
| Rainy    | Mild        | High     | No    | Yes         |
| Rainy    | Cool        | Normal   | No    | Yes         |
| Rainy    | Cool        | Normal   | Yes   | No          |
| Overcast | Cool        | Normal   | Yes   | Yes         |
| Sunny    | Mild        | High     | No    | No          |
| Sunny    | Cool        | Normal   | No    | Yes         |
| Rainy    | Mild        | Normal   | No    | Yes         |
| Sunny    | Mild        | Normal   | Yes   | Yes         |
| Overcast | Mild        | High     | Yes   | Yes         |
| Overcast | Hot         | Normal   | No    | Yes         |
| Rainy    | Mild        | High     | Yes   | No          |

### Building the Decision Tree

1. **Calculate initial entropy**:
   - 9 "Yes" and 5 "No" instances
   - Entropy = -(9/14)*log2(9/14) - (5/14)*log2(5/14) ≈ 0.940

2. **Calculate information gain for each attribute**:
   - Outlook: Gain ≈ 0.246
   - Temperature: Gain ≈ 0.029
   - Humidity: Gain ≈ 0.151
   - Windy: Gain ≈ 0.048

3. **Select best split** (highest gain): Outlook

4. **Recurse on subsets**:
   - For Sunny branch: 2 Yes, 3 No → further split needed
   - For Overcast branch: All Yes → leaf node
   - For Rainy branch: 3 Yes, 2 No → further split needed

5. **Continue splitting** until stopping criteria met

### Final Decision Tree:

```
[Outlook]
 ├── Sunny → [Humidity]
 │    ├── High → No
 │    └── Normal → Yes
 ├── Overcast → Yes
 └── Rainy → [Windy]
      ├── Yes → No
      └── No → Yes
```

### Interpretation:
- First check the outlook:
  - If overcast → play tennis
  - If sunny → check humidity (high → don't play, normal → play)
  - If rainy → check wind (windy → don't play, not windy → play)

This tree makes decisions similar to how a person might decide whether to play tennis based on weather conditions.

Working Steps:

1. Start at the root node (entire dataset).

2. Calculate entropy or Gini index for the dataset.

3. For each feature, calculate:
The Information Gain (if using Entropy), or
The Gini Gain (if using Gini Index).

4. Choose the best feature that gives the maximum gain.

5. Split the dataset based on that feature.

6. Repeat recursively for each branch until:
The node is pure, or
A stopping condition is met (like max depth, min samples, etc.)

7. The tree is then used for prediction by following decisions from root to leaf.

Decision Tree Parameters (Brief Overview)
Decision trees (both classification and regression) have key hyperparameters that control their behavior
to prevent overfitting and improve performance. Below are the most important ones:

1. Splitting Criteria
Classification Trees

criterion="gini" (Default) – Measures Gini impurity (faster).

criterion="entropy" – Uses information gain (slower but similar results).

Regression Trees

criterion="squared_error" (Default) – Minimizes mean squared error (MSE).

criterion="friedman_mse" – Improved MSE for gradient boosting.

criterion="absolute_error" – Uses mean absolute error (MAE).

2. Tree Size & Stopping Conditions
max_depth – Maximum depth of the tree (default=None, grows until pure).

min_samples_split – Minimum samples required to split a node (default=2).

min_samples_leaf – Minimum samples required at a leaf node (default=1).

max_leaf_nodes – Limits total leaf nodes (stops early if reached).

3. Handling Features & Splits
max_features – Number of features considered for splitting (default="auto").

"sqrt" → √n_features (common for Random Forests).

"log2" → log₂(n_features).

int/float → Fixed number/percentage.

4. Class Imbalance (Classification Only)
class_weight – Adjusts weights for imbalanced classes (e.g., class_weight="balanced").

5. Regression-Specific
min_impurity_decrease – Split must improve impurity by at least this value.
